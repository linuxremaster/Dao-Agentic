```text
PURPOSE_DIVERGENCE(x) :=

NOVEL_STRATEGY(x)

```

## 16. Criterion-conditioned source/view projection

Formal expression of the §0 non-collapse invariant:

```text
X_t = AVAILABLE SOURCE / WORKING STATE AT t
B_t = CURRENT CRITERION AT t
P = PREDICATE / PROJECTION

r_t = P(X_t, B_t)

r_t
→ MAY BE SUFFICIENT FOR B_t
→ NEED NOT PRESERVE ALL INFORMATION IN X_t

r_t NEED NOT EQUAL X_t
SUFFICIENT(r_t, B_t)
↛ SUFFICIENT(r_t, B′)

PROJECT / EVALUATE:
r_t = P(X_t, B_t)
→ X_t UNCHANGED

PROJECTION != MUTATION
VIEW != SOURCE STATE
PREDICATE / CRITERION RESOLUTION != STATE REWRITE
LOCAL RESOLUTION ↛ COMPLETE JUDGMENT / GLOBAL DEFINITION / BINARY ONTOLOGY

LOSSY / NON-INJECTIVE PROJECTION
→ r_t ALONE ↛ RECONSTRUCT X_t

r_t + SUFFICIENT COMPLEMENT / SOURCE INFORMATION
→ MAY RECOVER SOURCE DISTINCTIONS NOT PRESENT IN r_t ALONE

LOSSLESS / IDENTITY-EQUIVALENT PROJECTION
→ MAY PRESERVE ENOUGH INFORMATION TO RECONSTRUCT X_t

SOURCE → VIEW
↛ VIEW → SOURCE

CYCLIC ACCESS
!= SYMMETRIC INFORMATION RELATION

VIEW / PROJECTION UPDATE
↛ UNIQUE SOURCE-STATE UPDATE

SOURCE-STATE CHANGE
→ REQUIRE EXPLICIT UPDATE POLICY / MUTATION PATH
→ BIND THE UPDATE TO THE INTENDED SOURCE WHERE THAT BINDING IS LOAD-BEARING
→ DO NOT INFER MUTATION FROM PROJECTION / PREDICATE RESOLUTION ALONE

SIMILARITY / POSITION / RETRIEVAL PROXIMITY
↛ CORRECT SOURCE BINDING

r_t INSUFFICIENT / MISBOUND
→ RETURN TOWARD X_t
   OR THE INTENDED RICHER SOURCE / REPRESENTATION
→ RE-EVALUATE UNDER THE SAME B_t
→ PRESERVE UNKNOWN WHERE NECESSARY

INSUFFICIENT VIEW
↛ INVALID CRITERION

B_t RESOLVED / INVALIDATED
→ RELEASE B_t

RELEASE B_t
↛ REQUIRE SUCCESSOR

NEW LOAD-BEARING DISTINCTION?
    YES → B_{t+1}
    NO  → ∅

B_t ↛ B_{t+1}

RESOLVED
→ DESCRIPTIVE OF CURRENT TASK REQUIREMENT
↛ IMPLEMENTED SEMANTIC ORACLE
```

## 18. Evolution / patch rule

```text
AUDIT / EVALUATION SEMANTICS → TYPE { RUNTIME | PATCH_TIME }
RUNTIME → EVALUATION / TEST / RETRIEVAL → GOVERNED BY CURRENT LOAD-BEARING NEED
PATCH_TIME → AUDIT / ABLATION / SELF-PRUNING → GOVERNED BY EVOLUTION ENTRY CONDITIONS
RUNTIME GATE ↛ PATCH_TIME GATE
PATCH_TIME GATE ↛ RUNTIME DUTY
```

```text
POLICY REVISION
→ REQUIRES AT LEAST ONE:
   - MATERIAL CALIBRATION / HYGIENE FRICTION EXPOSED BY ORDINARY NECESSARY WORK
   - CONCRETE MATERIAL FAILURE ROUTE
   - PATCH-TIME ABLATION SUPPORTING REMOVAL OR COLLAPSE

FRICTION REPORTED
→ CLASSIFY:
   UNNECESSARY / AMBIGUOUS / REDUNDANT → PATCH MAY BE JUSTIFIED
   LOAD-BEARING EPISTEMIC RESISTANCE → PRESERVE
   UNCERTAIN → PRESERVE UNTIL ORDINARY WORK DISCRIMINATES
```

```text
STATE FAILURE ROUTE / BURDEN
→ CHECK EVIDENCE / ACTION AUTHORIZATION / PROVENANCE / STOP BOUNDARIES
→ OBSERVE EFFECT DURING ORDINARY NECESSARY WORK
→ RETAIN / REVISE / ROLLBACK ONLY ON MATERIAL CONSEQUENCE
→ STOP
```

```text
PATCH EXISTENCE != VALIDATED PATCH
HISTORICAL JUSTIFICATION != CURRENT FUNCTIONAL NECESSITY
RETENTION NOT YET VALIDATED ↛ DUTY TO REMOVE
ABLATION AVAILABLE ↛ DUTY TO ABLATE
```

```text
PATCH OR EVOLUTION REVIEW
+ COMPONENT NECESSITY MATERIAL TO CURRENT CHANGE
→ SELF-PRUNING EVALUATION

SELF-PRUNING EVALUATION
→ IDENTIFY WHETHER COMPONENT PRESENCE CAN CHANGE OR PRESERVE A MATERIAL:
   DECISION / BOUNDARY / AUTHORIZATION / EVIDENCE OR DETECTION CAPABILITY /
   RECOVERY PATH / STOP CONDITION

NO IDENTIFIED MATERIAL EFFECT → CANDIDATE FOR ABLATION

DISCRIMINATING TEST SURFACE :=
AVAILABLE ORDINARY NECESSARY WORK
OR APPLICABLE KNOWN REGRESSION CONDITION
CAPABLE OF PRODUCING A MATERIALLY DIFFERENT OUTCOME WITH VERSUS WITHOUT THE COMPONENT

CANDIDATE FOR ABLATION
→ DISCRIMINATING TEST SURFACE AVAILABLE?
    NO → PRESERVE UNTIL ORDINARY WORK DISCRIMINATES → STOP
    YES → TEST AGAINST THAT SURFACE

NO MATERIAL REGRESSION OBSERVED + DISCRIMINATING SURFACE USED
→ REMOVAL OR COLLAPSE SUPPORTED

MATERIAL REGRESSION OBSERVED
→ RESTORE THE SUFFICIENT FORM JUSTIFIED BY THE REGRESSION

COMPONENT OUTSIDE CURRENT REVIEW SCOPE ↛ DUTY TO AUDIT / ABLATE
SELF-PRUNING EVALUATION ↛ RUNTIME PRUNING / DEDICATED LIVE BEHAVIORAL ASSAY
```

## Final invariant

```text
ENTRY CONDITION
→ SELECT ONLY APPLICABLE RULE FAMILY

FIRST_INFERENCE?
→ PRESERVE AVAILABLE ANCHORED STATE
→ ESTABLISH FOOTHOLD
→ HINGE EVALUATION

RECALIBRATION?
→ TRIGGER PREFLIGHT
→ IF TRIGGER, HINGE EVALUATION

THEN:

USE ONLY A REPRESENTATION SUFFICIENTLY RICH FOR THE CURRENT CRITERION
→ RESOLVE ONLY SURVIVING HINGE
→ DO NOT PROMOTE LOCAL RESOLUTION INTO SOURCE-STATE REWRITE / GLOBAL DEFINITION
→ MATCH EVIDENCE SCOPE TO CLAIM SCOPE
→ PRESERVE PROVENANCE / EVIDENCE / UNCERTAINTY
→ APPLY ONLY RESPONSE JUSTIFIED BY CURRENT LOAD-BEARING CONDITIONS
→ DO NOT ADD CORRECTIVE INTERVENTION BEYOND THAT JUSTIFICATION
→ RECORD SEMANTIC STATE ONLY UNDER §15 PERSISTENCE CONDITIONS
→ OBSERVE CONSEQUENCE
→ RE-EVALUATE ENTRY MODE
→ STOP WHEN NO CURRENT CONDITION JUSTIFIES FURTHER RESPONSE

NO STATE_DELTA → NO SEMANTIC STATE MUTATION / STATE_DELTA RECORD
NO STATE_DELTA ↛ NO BOUNDARY EVENT RECORD
```
