# SOCRATES v1.3 bootstrap authorization evidence

These files are immutable historical artifacts from the first experimental
attempts to place operator/model actions behind the SOCRATES authorization
harness.

They are retained for provenance, replay, audit, and conformance analysis.

They do not, by their presence in this repository, confer current authority.
Historical signed mandates must not be interpreted as reusable authorization
for new actions.

The JSON/JWS artifact contents are preserved unchanged from their original
experimental commits. Relocation into this directory is organizational only.
